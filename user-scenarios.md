# Пользовательские сценарии

### 1. Регистрация пользователя
1. Пользователь открывает сайт.
2. Переходит на страницу регистрации.
3. Вводит необходимые данные.
4. Система проверяет введённые данные и создаёт аккаунт.
5. Пользователь получает доступ к своему аккаунту.

### 2. Авторизация пользователя
1. Пользователь открывает страницу входа.
2. Вводит логин и пароль.
3. Система проверяет правильность данных.
4. При успешной проверке пользователь входит в свой аккаунт.

### 3. Просмотр доступных зонтов
1. Пользователь открывает каталог зонтов.
2. Система отображает список доступных для аренды зонтов.
3. Пользователь выбирает подходящий зонт и просматривает информацию о нём.

### 4. Оформление аренды
1. Пользователь выбирает доступный зонт.
2. Нажимает кнопку оформления аренды.
3. Система проверяет, доступен ли зонт для аренды.
4. Если зонт доступен, система создаёт запись об аренде и обновляет его статус.
5. Пользователь получает подтверждение оформления аренды.

### 5. Завершение аренды
1. Пользователь открывает информацию о своей текущей аренде.
2. Возвращает зонт в предусмотренное для этого место.
3. Подтверждает завершение аренды в системе.
4. Система завершает аренду и обновляет статус зонта, делая его доступным для следующих пользователей.
